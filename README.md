# Projecte de Prova MkDocs

Aquest projecte és una pràctica per aprendre a crear documentació estàtica amb **MkDocs** i el tema **Material for MkDocs**. L'objectiu és generar un lloc web a partir de fitxers Markdown i publicar-lo a GitHub Pages.

## Objectius de la pràctica

- Configurar un entorn virtual de Python.
- Instal·lar Material for MkDocs amb pip.
- Escriure documentació en Markdown.
- Publicar el lloc a GitHub Pages.

## Com executar el projecte

Per a previsualitzar el lloc localment, cal activar l'entorn virtual i executar:

```bash
mkdocs serve
